TEST CASE BÀI J1.S.P0071 - TASK MANAGEMENT
==========================================================================

Cách dùng:
- Mở file này song song với NetBeans, chạy lần lượt từng nhóm.
- Đánh dấu [x] khi kết quả giống cột "Mong đợi".
- Sai chỗ nào thì sửa code rồi chạy lại TOÀN BỘ các nhóm, không chỉ case vừa sửa.

Quy ước:
- (Enter)  = để trống, nhấn Enter luôn.
- "Báo lỗi" = in thông báo lỗi rồi HỎI LẠI đúng câu đó, chương trình không crash.
- Nội dung thông báo lỗi do bạn tự đặt (đề không quy định), miễn rõ nghĩa.

CÁC CASE TỪNG BỊ LỖI Ở BẢN TRƯỚC (test kỹ nhất):
  B10 (chọn 4 không thoát được)        D7 (xóa xong tự in bảng)
  D9  (xóa bị crash)                   E2 (ID bị trùng)
  C16-C21 (ngày không tồn tại vẫn nhận) C30-C32 (giờ 9.3, From = To vẫn nhận)
  A7  (Time in ra 8,0)

[ ] A1  Menu (ô 1):
            ========= Task program =========
                1. Add Task
                2. Delete task
                3. Display Task
                4. exit
        - Tiêu đề: 9 dấu "=" + cách + "Task program" + cách + 9 dấu "="

            Requirement Name: -> Task Type: -> Date: -> From: -> To: -> Assignee: -> Reviewer:

            ---------Del Task------
            ID:

[ ] A5  Tiêu đề bảng (ô 4): 41 dấu "-" + " Task " + 39 dấu "-"
            ----------------------------------------- Task ---------------------------------------

[ ] A6  Tên cột đúng thứ tự: ID | Name | Task Type | Date | Time | Assignee | Reviewer

[ ] A7  Cột Time in "8.0": dấu CHẤM, 1 chữ số sau dấu chấm. Không được "8,0" hay "8.00"

[ ] A8  Cột Task Type in TÊN loại (Code / Test / Design / Review), không in số 1-4

[ ] A9  Sau chức năng 1, 2, 3 đều quay lại menu
